# 如何使用本教程

这套讲义讨论三个相互关联的问题：模型如何计算、训练如何验证、结构如何实验。完成全部主线后，你应能解释一个现代 Decoder-only 模型的主要张量路径，检查自己的实现，并设计有边界的结构对照实验。

## 你需要哪些基础

应当能够编写 PyTorch 的基本训练循环，理解梯度、优化器和训练／验证划分。不要求先掌握分布式训练，也不要求拥有能训练大模型的集群。已有目标检测经验的读者，可以重点补充序列维度、因果掩码、Token 化和自回归推理。

## 推荐阅读顺序

1. **基础模型：00—05。** 先建立张量与训练目标的对应关系，然后组装模型、检查正确性，最后固定正式实验的数据管线。
2. **现代组件：06—09。** 每次替换一个模块，分析预算变化，再加入缓存和高效实现。
3. **架构研究：10—13。** 先设计可解释的对照，再进入长上下文、MoE 和真实模型。

每章末尾有验收条件。没有通过时先定位问题，无需赶章节进度。数学推导、代码阅读、实际训练与系统性能是不同能力，应分别记录完成情况。

## 资源分档

| 条件 | 适合的任务 | 不应据此声称完成 |
| --- | --- | --- |
| 只有 CPU | 小张量计算、mask 检查、微型模型过拟合、源码阅读 | GPU 吞吐率或规模化训练结论 |
| 单张 GPU | 小模型训练、组件对照、缓存和性能测量 | 大模型能力、跨节点通信收益 |
| 多 GPU | 另行研究数据／张量／专家并行 | 与单卡实验直接公平比较 |

正式长跑前先做短试跑，记录实际 Token/s、峰值显存和预计总时长。模型参数量无法单独决定资源需求，还要考虑序列长度、批量、激活、优化器和数据管线。

## 内容与代码状态

当前是持续完善的首版讲义。短代码用于阐明计算过程；需要 PyTorch 的片段未在本仓库配套运行环境中执行，使用前应完成章节要求的数值检查。没有给出未经执行的训练指标。

后续章节可逐步加入完整代码、自动检查、Notebook 与参考实验。MLA 的完整实现、GDN、MTP、量化、Triton 和多卡并行作为专题扩展，不是读完基础主线的前置要求。

## 阅读约定

- $B$：batch size；$T$：序列长度；$D$：模型隐藏维度。
- $H_q$、$H_{kv}$：Query 与 KV 头数；$d_h$：头维度。
- 代码与公式都明确 shape，时间和显存都注明测量条件。
- 微型实验用于理解局部机制，不把其结果直接推广到大规模模型。
