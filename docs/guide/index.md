# 阅读指南与全书大纲

本书讨论三个相互关联的问题：模型如何计算，训练结果如何验证，结构改动如何比较。主线从自回归预测出发，先构造可信的小模型，再理解现代组件与推理，最后设计有边界的架构实验。

## 适合谁读

读者应能编写 Python 程序，理解 PyTorch 张量、梯度、优化器和训练／验证划分。已有目标检测经验的读者不必从普通深度学习入门课重学，但需要建立序列维度、因果性、Token 化与自回归推理的概念。

不要求有 GPU 集群。主线每章都有自包含的 CPU 实验；更大的数据、模型与系统优化属于扩展任务。先完成正确性检查，再扩大训练规模。

## 先修关系

00—04 构成基础模型与训练主线；05 固定文本和样本管线。06 依赖注意力与 GPT 的计算路径；07 依赖多头注意力；08 同时需要位置编码和头分组。09 在计算正确后研究实现效率。10、11 分别展开长上下文与条件计算，12 将概念映射回固定版本的真实模型，13 汇总为独立实验。

章节在概念上有先修关系，实验在代码上可以独立运行：每个入口都包含自己的模型、配置和小数据，不导入前章文件。这样读者可以单独复制一章的实验；代价是部分基础代码有意重复。

## 每章怎样学

1. 先说明输入、输出、张量形状与要验证的问题。
2. 阅读推导和关键实现，运行本章 `--quick` 检查。
3. 检查 JSON 报告，区分正确性误差、训练结果和计时数据。
4. 修改一个变量，运行常规规模或另一个随机种子，记录变化。
5. 完成习题，再阅读下一章。不要用更长训练代替失败的数值检查。

安装、各章目录和统一入口见[运行实验](/labs)。数学排版中的 $B$ 表示批量，$T$ 表示序列长度，$D$ 表示隐藏维度，$H_q$ 和 $H_{kv}$ 表示 Query 与 KV 头数，$d_h$ 表示头维度；具体章节若采用不同记法会另行说明。

## 实验与结论的范围

| 条件 | 可以完成的工作 | 结论的边界 |
| --- | --- | --- |
| CPU | 小张量对照、微型模型训练、代数验证、源码分析 | 无法推断 GPU 吞吐与大模型能力 |
| 单张 GPU | 自行扩展小模型训练、缓存与性能测量 | 需另行报告驱动、精度、内核与显存口径 |
| 多 GPU | 进一步研究数据、张量、专家并行 | 本书独立 CPU 实验未验证跨卡通信 |

微型语料的过拟合不代表语言泛化；合成任务不代表真实长上下文能力；理论缓存预算不等于进程峰值内存。Qwen 和 DeepSeek 的案例固定具体来源，只验证教学缩小版本的计算关系，不是对官方权重、训练配方或性能的完整复现。

在比较结构前阅读[统一实验规范](/experiments)。如果实验失败，保留原始报告、环境版本和种子；如果没有收益，也应如实记录。MLA 的完整系统实现、量化、Triton、多 Token 预测和多卡并行可作为后续专题，不作为完成主线的前置条件。
