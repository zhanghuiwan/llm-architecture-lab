# 00 必要准备：把张量当作计算地图

一个语言模型可以由许多模块组成，但定位错误时，最可靠的起点往往是一个 shape。你需要追踪：某个维度表示样本、位置、通道，还是注意力头？

本章目标是能从 `[B,T,D]` 出发，解释多头注意力的形状变换与梯度路径。

## 从目标检测迁移已有经验

检测网络常用 `[B,C,H,W]` 表示特征。语言模型常用 `[B,T,D]`：$T$ 是序列中的位置，$D$ 是每个位置的表示维度。Attention 将不同位置关联起来；FFN 通常独立地作用于每个位置，参数在位置之间共享。

| 概念 | 在语言模型中要注意什么 |
| --- | --- |
| Batch | 同批样本可能长度不同，padding 需要单独处理 |
| 通道／隐藏维度 | 不要与注意力头数、词表大小混淆 |
| 感受野 | 因果 mask 决定一个位置能够读取哪些 Token |
| 训练与推理 | 训练常并行处理整段序列，生成则逐步追加 Token |

## 形状练习

设 $B=2,T=8,D=32,H=4$。每个头的维度为 $d_h=D/H=8$。

```python
import torch

B, T, D, H = 2, 8, 32, 4
x = torch.randn(B, T, D)
q = x.reshape(B, T, H, D // H).transpose(1, 2)
assert q.shape == (B, H, T, D // H)

# transpose 后通常不再连续，合并维度前显式恢复内存布局。
y = q.transpose(1, 2).contiguous().view(B, T, D)
torch.testing.assert_close(x, y)
```

这里没有学习新的表示，只改变了同一批数值的组织方式。线性投影随后才引入可学习的参数。

## 数值与梯度

掌握 `reshape`、`transpose`、`matmul`、广播和 `softmax` 的作用维度。知道 `model.eval()` 与 `torch.no_grad()` 的区别：前者影响 dropout 等模块行为，后者控制梯度记录。

做数值对照时先用 FP32，固定输入和权重，关闭随机层。之后才引入 BF16、融合算子和设备差异，并制定合理的绝对／相对误差。
