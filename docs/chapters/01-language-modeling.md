# 01 语言模型在学什么

语言模型学习序列的概率。对一个从左向右生成的模型，联合概率按条件概率分解：

$$
p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t}).
$$

训练数据提供已知序列，模型需要在每个位置预测后一个 Token。Token 可以是字符、字节、子词或其他离散单位。

## 输入与标签错开一位

假设编码结果为 `[4,7,2,9,3]`，一个训练样本可以写成：

```text
输入： [4, 7, 2, 9]
标签： [7, 2, 9, 3]
位置：  0  1  2  3
```

位置 0 的输出读取 Token 4，预测 Token 7。位置 1 可以读取 4 与 7，但不能读取位置 2 的输入 2。训练时输入完整序列并不等于允许读取未来；访问范围由因果 mask 约束。

## 从隐藏向量到损失

隐藏状态为 `[B,T,D]`，LM Head 将它映射到 `[B,T,V]`，其中 $V$ 为词表大小。每个位置产生 $V$ 个未归一化分数，即 logits。

```python
import torch.nn.functional as F

# logits: [B, T, V]；labels: [B, T]
loss = F.cross_entropy(
    logits.reshape(-1, logits.size(-1)),
    labels.reshape(-1),
    ignore_index=-100,
)
```

`cross_entropy` 接收 logits，通常不要先手动 softmax。用于 padding 或不参与训练的位置可将标签设为约定的忽略值。此代码假定所有纳入统计的 Token 等权。

## 训练与生成的区别

训练通常使用 teacher forcing：每个位置的历史来自真实文本。生成时将模型选出的 Token 追加到上下文，再预测下一个 Token。因此，训练损失下降不保证长段生成质量，也不保证模型能够遵循聊天指令。

Greedy 每步选最大概率 Token；温度采样改变分布尖锐程度。比较生成样本时应固定 prompt、采样规则和随机种子，不挑选最好看的个别结果作为全部证据。

## 动手任务

用字符词表编码一小段文本，打印输入、标签和各位置预测目标。比较随机初始化模型的 loss 与 $\log V$ 的量级；它只是均匀预测的参考值，不是所有初始化必须精确满足的等式。

## 验收标准

- 能解释为什么输入与标签要错开一位。
- 能说明 padding mask、causal mask 和 loss mask 各自的职责。
- 不把基础语言建模与聊天对齐混为一个训练目标。
