# 06 现代 Transformer Block

前面已经实现了一个能够训练的 GPT。本章不继续扩大模型，而是拆开现代 Decoder-only 模型中常见的组件：RMSNorm、RoPE、SwiGLU、QK 归一化以及输入输出权重绑定。学习这些名称的目标，是能够沿着张量路径解释它们做了什么、统计它们增加或减少的参数，并为每个实现建立数值检查。

这些组件经常一起出现，但不存在唯一的“现代标准 Block”。真实模型对归一化位置、投影偏置、头数、RoPE 维度、权重共享和中间维度都有具体选择。一次替换全部组件，不能回答其中某个组件是否有效；本章先分别验证局部计算，再把它们放进一个小 Block。

## 6.1 学习目标与先修关系

读完并运行实验后，应能完成以下工作：

- 从公式写出 RMSNorm，解释它与 LayerNorm 的区别，以及 `eps` 和累加精度的作用。
- 明确 RoPE 的通道配对、频率、旋转维度和位置编号，验证相对位置关系。
- 根据参数预算选择 SwiGLU 中间维度，避免把同宽度误认为等参数。
- 在 `[B,H,T,d_h]` 上实现逐头 QK 归一化，理解它不是 softmax 的替代品。
- 说明 embedding/head 权重绑定的参数与梯度变化，检查组合 Block 的因果性。

需要先理解[因果多头注意力](/chapters/02-attention)和[最小 GPT](/chapters/03-minimal-gpt)。本章实验代码自包含，不导入前章文件；完整入口是 [experiments/06-modern-block/main.py](https://github.com/zhanghuiwan/llm-architecture-lab/blob/main/experiments/06-modern-block/main.py)。

本章使用 $B$ 表示批量、$T$ 表示序列长度、$D$ 表示隐藏维度、$H$ 表示注意力头数、$d_h=D/H$ 表示头维度，$M$ 表示 FFN 中间维度。实验采用完整维度的 RoPE、无偏置投影和相同的 Q/K/V 头数，暂不引入 GQA 和缓存。

## 6.2 先明确 pre-norm 的残差路径

一个 pre-norm Block 可以写成两次残差相加：

$$
U=X+\operatorname{Attention}(N_a(X)),\qquad
Y=U+\operatorname{FFN}(N_f(U)).
$$

$X,U,Y$ 都是 `[B,T,D]`。$N_a$ 和 $N_f$ 使用各自独立的归一化参数。这里“pre”表示在子层之前归一化，残差支路直接传递未经过该次归一化的表示。不要把第二项写成 `norm(x + branch(x))`，那会改变为另一种结构。

这个表达式提供了一个有用的检查：将注意力输出投影和 FFN 下投影全部置零，两个分支输出都为零，整个 Block 应精确返回输入。这个检查不能证明训练稳定，却能发现把归一化放到残差相加之后等结构错误。

最终语言模型通常还会在全部 Block 后加入一次归一化和词表投影。本章组合实验只研究一个 Block；词表端的权重绑定在单独的计算图中验证。不要把本章参数总数当成完整语言模型的总参数。

## 6.3 RMSNorm：沿最后一维缩放

对一个位置的向量 $x\in\mathbb{R}^{D}$，RMSNorm 定义为：

$$
r(x)=\sqrt{\frac{1}{D}\sum_{j=1}^{D}x_j^2+\epsilon},\qquad
y_i=\gamma_i\frac{x_i}{r(x)}.
$$

$\gamma$ 是 `[D]` 的可学习缩放，广播到批量和序列维度。输入 `[B,T,D]` 时，均值只沿最后一维计算，并用 `keepdim=True` 保留 `[B,T,1]`。沿 `T` 归一化会让一个位置依赖其他位置，对自回归模型甚至可能引入未来信息。

实验的核心实现如下：

```python
def rms_norm(x, weight, eps=1e-6):
    return x * torch.rsqrt(x.square().mean(-1, keepdim=True) + eps) * weight
```

这段函数本身并不选择累加精度。实验把输入和权重显式设为 FP64，以便进行严格的数值与梯度对照。在低精度训练中，平方和可能需要升到 FP32 累加，再按模型约定转换回输入类型；具体行为应与目标实现一致，不能仅凭函数名判断。

LayerNorm 通常先减均值，再除以标准差，并可能包含偏置。RMSNorm 不减均值，因此不能将其描述为“只去掉一个无关步骤的 LayerNorm”。给输入加一个常数后，RMSNorm 的输出通常会改变；实验同时计算两种归一化，确认它们不是同一个函数。

当 $\epsilon=0$ 且缩放系数 $c>0$ 时，有 $N(cx)=N(x)$。这个尺度性质有条件：有限的 `eps` 会打破严格等式；负缩放还会改变符号。实验只在明确设置 `eps=0` 的非零随机输入上检查该性质，不把它推广到所有数值情况。零输入配合正 `eps` 则应给出有限的零输出。

### 前向相同仍要检查梯度

向量化实现与显式逐位置循环分别构造同一个输出，再与同一随机探针相乘后求和。对输入和 $\gamma$ 的梯度都应一致。随后 `torch.autograd.gradcheck` 使用小尺寸 FP64 输入，以有限差分检查解析梯度。较大的真实 Block 不必对每个元素做差分；选择小输入能检查公式，同时控制检查成本。

注意“输出 RMS 接近 1”也有条件：只有 $\gamma=1$、`eps` 相对输入均方足够小时才近似成立。存在学习后的缩放向量时，不应断言输出向量的长度固定。

## 6.4 RoPE：旋转 Query 与 Key

注意力分数来自 $q_t^\top k_s$。如果没有任何位置机制，单靠内容向量不能明确表达 Token 的先后。RoPE 把位置写入 Q/K 的旋转角度。本实验对每个头的相邻偶奇坐标配对：第 $i$ 对是 $(x_{2i},x_{2i+1})$。

设头维度为偶数 $d_h$，基数为 $b_0$，第 $i$ 对的频率和位置角度为：

$$
\omega_i=b_0^{-2i/d_h},\qquad
\theta_{t,i}=t\omega_i,\qquad 0\le i<d_h/2.
$$

每个通道对应用二维旋转：

$$
\begin{bmatrix}x'_{2i}\\x'_{2i+1}\end{bmatrix}
=
\begin{bmatrix}
\cos\theta_{t,i}&-\sin\theta_{t,i}\\
\sin\theta_{t,i}&\cos\theta_{t,i}
\end{bmatrix}
\begin{bmatrix}x_{2i}\\x_{2i+1}\end{bmatrix}.
$$

本章设置 $b_0=10000$，这是教学配置，不是对任意真实模型的配置断言。不同模型可以采用不同基数、只旋转一部分通道，或引入额外的长上下文缩放。

### 广播与形状

Q/K 已拆头为 `[B,H,T,d_h]`。位置向量为 `[T]`，频率向量为 `[d_h/2]`，二者外积形成角度表 `[T,d_h/2]`。Q 的偶数和奇数切片都为 `[B,H,T,d_h/2]`，因此角度表可以沿批量和头广播。

```python
inv_freq = base ** (-torch.arange(0, d, 2, dtype=x.dtype) / d)
theta = positions[:, None] * inv_freq[None, :]
even, odd = x[..., 0::2], x[..., 1::2]
rotated = torch.stack((
    even * theta.cos() - odd * theta.sin(),
    even * theta.sin() + odd * theta.cos(),
), dim=-1).flatten(-2)
```

完整代码还处理输入设备与类型。不要把 `theta` 错误地构造成 `[d_h/2,T]`；当两个维度碰巧相等时，错误可能不会触发 shape 异常。本实验特意使用不同的序列长度与头内维度。

## 6.5 RoPE 应满足哪些性质

旋转矩阵正交，因此每对坐标的平方和保持不变。位置为零时，旋转应返回原输入；再施加相反位置的旋转，应恢复原向量。这些是实现层面的代数检查，与模型是否训练成功无关。

RoPE 更重要的关系是：

$$
(R_tq)^\top(R_sk)=q^\top R_{s-t}k.
$$

对所有 Query 和 Key 的位置同时加上相同常数 $c$，两两分数不变，因为相对位置没有改变。实验构造完整的 `[B,H,T,T]` 分数矩阵，比较原始位置与统一偏移 17 的位置。这也解释了为什么有绝对位置编号的实现仍能在点积中体现相对关系。

但只改变 Q 的位置，或让缓存中 K 的位置重新从零开始，会改变相对关系。实验保留一个故意错误的 Key 位置分支，要求分数确实发生变化。这样的负向对照说明检查能识别某类错误；不能只运行两个碰巧调用同一函数的路径后宣称独立验证。

RoPE 的位置公式可以计算到训练长度之外，这不等于模型能可靠处理任意长上下文。频率、训练分布、注意力可见范围和数值精度都会影响外推。长上下文能力在[第 10 章](/chapters/10-long-context)中作为独立问题讨论。

### 相邻配对与分半配对

有的实现把前半维与后半维配对，而不是相邻偶奇配对。两种写法在匹配的通道置换下可以等价。实验构造置换 `[0,2,4,...,1,3,5,...]`，先重新排列向量，再使用分半写法，最后与相邻写法的同一排列比较。

不能把同一组投影权重保持不变，仅替换 `rotate_half` 的写法就假定结果相同。加载外部权重时，通道布局是模型契约的一部分；若要转换，必须对相关权重和张量使用一致的置换。本章同时检查“经过正确转换可等价”和“省略转换会不同”。

## 6.6 SwiGLU：门控路径也占参数

普通无偏置 FFN 通常写为：

$$
\operatorname{FFN}(x)=\phi(xW_1)W_2,
$$

其中 $W_1\in\mathbb{R}^{D\times M}$，$W_2\in\mathbb{R}^{M\times D}$，参数量为 $2DM$。

SwiGLU 引入两条上投影路径：

$$
\operatorname{SwiGLU}(x)
=\left[\operatorname{SiLU}(xW_g)\odot(xW_u)\right]W_d,
\qquad
\operatorname{SiLU}(a)=a\sigma(a).
$$

$W_g,W_u$ 都是 `[D,M]`，$W_d$ 是 `[M,D]`，参数量为 $3DM$。门控是逐元素乘法，输出仍是 `[B,T,D]`。这里没有要求门值在 0 到 1 之间：SiLU 输出可以为负，也不以 1 为上界，不应把它简单理解为一个概率开关。

### 为什么常见中间维度约为 8D/3

若基线 FFN 采用 $M_0=4D$，则参数量为 $8D^2$。要让 SwiGLU 保持相同的无偏置参数预算，需要：

$$
3DM=8D^2\quad\Longrightarrow\quad M=\frac{8D}{3}.
$$

真实系统可能为张量并行或矩阵核效率将 $M$ 取整到特定倍数，也可能主动改变预算。若两种 FFN 都设为 $4D$，SwiGLU 会拥有更多参数，不能把实验收益全部归因于激活函数或门控。

本章快速配置选择 $D=24$、$M=64$，两种 FFN 都有 4608 个参数；常规配置采用 $D=48$、$M=128$。这里为了精确核算选择可整除的维度，并没有测试这些宽度的硬件效率。

### 合并投影不改变函数

将 $W_g$ 和 $W_u$ 沿输出维拼接，可以通过一次较宽的矩阵乘法得到两个分支，再 `chunk` 分开。实验比较分离投影与合并投影，不仅核对前向，还核对输入及三个权重的梯度。

“合并为一次调用”不保证端到端更快，尤其在小尺寸 CPU 上可能受调度和分配影响。本章只验证代数等价，实际计时方法见[第 09 章](/chapters/09-performance)。实验还故意省略 SiLU，确认结果不同；这个错误仍保持全部 shape 正确。

## 6.7 QK 归一化：头内轴不能写错

本章的 QK-Norm 对每个头的 Q 和 K 分别应用 RMSNorm：

$$
\widehat q_{b,h,t,:}=N_q(q_{b,h,t,:}),\qquad
\widehat k_{b,h,t,:}=N_k(k_{b,h,t,:}).
$$

输入为 `[B,H,T,d_h]`，均方计算沿最后的 $d_h$ 维度，Q 与 K 各有一个 `[d_h]` 的缩放参数，并在所有头上共享。这里定义的是本章实现，不表示所有架构都会以相同方式共享参数。

归一化发生在 RoPE 之前，随后仍然计算缩放点积并做 causal softmax。QK-Norm 调整 Q/K 的幅度统计，softmax 则将某个 Query 对各个 Key 的分数变成权重，二者作用与轴都不同。RMSNorm 也不是单位长度的 L2 归一化：当缩放为 1、忽略 `eps` 时，平方和接近 $d_h$，而不是 1。

实验将正确的逐头结果与显式均方公式比较，同时构造“跨所有头和头内通道共同归一化”的错误分支。这种错误同样输出 `[B,H,T,d_h]`，只有数值或轴语义检查才能发现。独立实验时应把归一化位置、缩放是否共享、`eps` 和是否仍使用 $1/\sqrt{d_h}$ 一起写入配置。

## 6.8 将组件组合成一个小 Block

组合实验依次执行以下路径：

```text
X [B,T,D]
 ├─ RMSNorm → QKV projection → reshape [B,H,T,d_h]
 │              Q,K: per-head RMSNorm → RoPE
 │              causal SDPA → merge heads → output projection
 └─ residual add → U [B,T,D]
                  ├─ RMSNorm → gate/up → SiLU × up → down
                  └─ residual add → Y [B,T,D]
```

所有投影不带偏置。Q/K/V 投影共 $3D^2$ 参数，输出投影为 $D^2$，SwiGLU 为 $3DM$，两次隐藏维 RMSNorm 为 $2D$，Q/K RMSNorm 为 $2d_h$。因此该 Block 的总参数为：

$$
P_{\text{block}}=4D^2+3DM+2D+2d_h.
$$

快速配置的参数数是 6976。代码通过 `sum(p.numel() for p in block.parameters())` 核对这个数，而不是只打印理论值。真实模型若有偏置、不同 KV 头数、其他门控或额外归一化，需要重新计算。

组合检查包括输出形状、全部参数及输入的有限梯度、前缀因果性、共同位置偏移不变性，以及零分支时的残差恒等性。未来输入扰动发生在位置 3 及之后，前 3 个输出应保持不变。这个检查覆盖整个 Block 的归一化、注意力和 FFN 路径；局部性质通过不意味着组合一定正确。

## 6.9 权重绑定：同一参数接收两条梯度路径

Embedding 权重 $E$ 的形状为 `[V,D]`。输入 Token 根据编号取出对应行，得到隐藏表示；LM Head 可以使用 $E^\top$ 投影到词表，即 `F.linear(hidden, E)`。绑定权重表示二者是同一个 `Parameter`，不是初始化时复制相同数值后独立更新。

若原本 embedding 与 head 都没有偏置，绑定可节省 $VD$ 个参数。实验中 $V=19$、$D=24$，因此节省 456 个参数。若有输出偏置，它属于另外的参数，不能随着绑定一起省略统计。

同一参数参与输入查表和输出分类，其梯度应为两条路径贡献之和。实验建立两张计算图：一张使用共享权重，另一张让 embedding 和 head 使用数值相同但独立的权重。初始前向应相同，并且：

$$
\nabla_E L_{\text{tied}}
=\nabla_{E_{\text{input}}}L_{\text{untied}}
+\nabla_{E_{\text{output}}}L_{\text{untied}}.
$$

这不表示两种模型经过一次优化后仍相同。独立权重各自更新，共享权重按合并梯度更新，之后轨迹会分离。绑定是一种结构约束，参数更少并不自动等于能力更强。

代码还检查 `head.weight is embedding.weight`，并使用 `parameters()` 的去重统计核对实际参数量。仅检查 `torch.equal` 不足以证明绑定，因为两个独立参数也可能有完全相同的初始数值。

## 6.11 常见错误与排查顺序

**输出形状正常但结果不一致。** 先打印归一化轴、Q/K 头维度、RoPE 的配对约定与实际位置编号。错误轴、漏掉 SiLU、分半布局与相邻布局混用，都可能保持相同 shape。用小输入比较中间张量，不要只检查最终 loss 是否有限。

**读取外部权重后结果偏差大。** 核对投影权重的布局、Q/K 是否有归一化、RoPE 是否仅覆盖部分维度、输出是否绑定。不能将模型名字相似当作结构相同。本章教学 Block 没有实现具体 Qwen 或 DeepSeek 的全部约定，源码分析留到第 12 章。

**RoPE 数值检查通过，长文本仍失败。** 代数正确只说明实现了选定旋转函数，不说明训练产生了相应能力。不要用“支持传入更大位置”替代长上下文任务评测，也不要通过放宽测试阈值掩盖位置偏移错误。

**换成 SwiGLU 后参数更多。** 检查是不是沿用了普通 FFN 的 $4D$ 中间维度，是否计入三组矩阵、偏置和取整。若主要实验预算是参数量，应先匹配预算；若主要预算是时长或 FLOPs，则另行报告参数差异。

**绑定后参数统计翻倍。** 确认两个模块引用同一个对象，避免分别构造优化器参数列表时重复添加。复制权重和共享权重不是一回事；统计 `state_dict` 的键数也不等于独立可训练参数个数。

## 6.12 练习与提示

1. **改变 RMSNorm 的归一化轴。** 保持输出 shape 不变，找出一个会让过去输出依赖未来输入的错误版本。提示：沿序列维计算统计量，再使用本章前缀扰动测试。请在复制的实验文件中探索，保留原始正确性入口。
2. **实现部分 RoPE。** 只旋转前一半头通道，其余保持不变。提示：旋转部分的维度仍需为偶数，先说明频率分母采用旋转维度还是完整头维度，再验证配对范数与共同偏移性质。
3. **让 FFN 预算无法整除。** 选择 $D=32$，将 $8D/3$ 向上或按 16 的倍数取整，计算参数误差。提示：同时报告理想值、实际 $M$ 和实际 $3DM$，不要只写“近似等参数”。
4. **修改 QK-Norm 缩放参数。** 比较 `[d_h]` 共享与 `[H,d_h]` 逐头参数化。提示：广播位置与参数数都会改变，前向形状不能区分两种结构。
5. **对权重绑定做一次真实优化。** 从相同初值开始，分别优化绑定与不绑定模型一步，比较权重和输出。提示：第一次前向相同不意味着梯度更新相同；先核对两条梯度路径，再解释分离。
6. **设计单因素训练实验。** 在同一个小型 GPT 中只替换 LayerNorm 为 RMSNorm，固定数据、Token 预算和随机种子，并报告所有额外配置变化。提示：本章 39 项检查不包含训练优劣结论，需要自行实际执行，按[统一实验规范](/experiments)记录结果。
